## ✅ Интеграция Kagglehub

### Добавлены файлы:

#### 1. **scripts/download_kaggle_dataset.py** (~250 строк)
Основной скрипт для загрузки и интеграции датасетов с Kaggle.

**Функции:**
- Загрузка датасетов через `kagglehub.dataset_download()`
- Парсинг PDF, TXT, MD файлов
- Нормализация текста (удаление спецсимволов, лишних пробелов)
- Добавление метаданных (источник, тип файла, дата)
- Индексация в ChromaDB с полной интеграцией в RAG пайплайн
- Информативные логи операций

**Параметры:**
```bash
--dataset "username/dataset-name"   # ID датасета (по умолчанию rplan-dataset2025)
--output path/to/output             # Директория сохранения
--integrate-rag                     # Индексировать в ChromaDB
--no-normalize                      # Пропустить нормализацию
--list                              # Показать популярные датасеты
```

#### 2. **examples/quick_kaggle_load.py** (~40 строк)
Упрощённый пример для быстрой загрузки датасета.

**Использование:**

## 🔄 Поток работы

```
1. Пользователь запускает:
   python scripts/download_kaggle_dataset.py \
     --dataset "lkerkarabulut/rplan-dataset2025" \
     --integrate-rag

2. Скрипт:
   ├── Загружает датасет через kagglehub
   ├── Парсит PDF/TXT/MD файлы
   ├── Нормализует текст
   ├── Добавляет метаданные
   └── Индексирует в ChromaDB

3. В RAG доступны:
   ├── Запросы на основе плана этажей
   ├── Поиск архитектурных норм
   ├── Примеры типовых решений
   └── Классификация стилей

4. Через веб-интерфейс:
   ./start_webapp.sh
   # Чат → включить RAG → запросить информацию о плане
```

## 📝 Примеры использования

### Базовое использование

```bash
# 1. Установить kagglehub
pip install -r requirements.txt

# 2. Аутентифицироваться
kagglehub auth login

# 3. Загрузить датасет
python scripts/download_kaggle_dataset.py

# 4. Запустить веб-приложение
./start_webapp.sh

# 5. Через чат запросить:
# "Какие стандартные размеры комнат?"
# "Покажи примеры планов квартир"
```

### Продвинутое использование

```bash
# Загрузить несколько датасетов
for dataset in "lkerkarabulut/rplan-dataset2025" \
               "zahidshakoor/construction-cost-dataset" \
               "titir2/architectural-heritage-elements"; do
    python scripts/download_kaggle_dataset.py \
      --dataset "$dataset" \
      --integrate-rag
done

# Проверить интеграцию
python -c "from src.rag_pipeline import get_rag; rag = get_rag('simple'); print(f'Total chunks: {rag.count()}')"
```
