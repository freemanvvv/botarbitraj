## 🏗️ Архитектура

```
LM Studio (локальные модели на порту 1234/v1)
    ├── Qwen3-14B (сметы, агент, инженерный текст)
    ├── Qwen3-8B (быстрые ответы)
    └── Llama-3.1-8B-Uz (узбекский язык)
            ↓
Python Router (маршрутизация по языку/сложности)
    ├── Phase 1: RAG + документы (ChromaDB + LlamaIndex)
    ├── Phase 2: Сметы и BOQ (SQLite + openpyxl) — 🔄 в разработке
    └── Phase 3: BIM/IFC (IfcOpenShell)
            ↓
Web App (FastAPI 8765 + React+Vite 5173)
    ├── Backend: чат, RAG, генерация, сметы
    ├── Frontend: 3 вкладки (Архив, Чат, Моделирование)
    └── Three.js для 3D-просмотра IFC
```

## ⚠️ Выявленные проблемы и gap'ы

### 🔴 High Priority Issues

1. **Phase 2 (Сметы) — неполная реализация**
   - Проблема: `estimate_engine.py` написан, но не интегрирован в веб-приложение
   - Статус: Нет маршрута `/estimate` в backend, нет UI-компонента
   - Решение: Завершить реализацию, добавить тесты, интегрировать в UI
   - Время: ~2-3 дня

2. **Отсутствие централизованного логирования**
   - Проблема: Везде `print()`, нет structured logging
   - Статус: Затрудняет отладку в production
   - Решение: Внедрить `loguru` или `python-json-logger`
   - Время: ~1 день

3. **OCR не интегрирован в RAG пайплайн**
   - Проблема: pytesseract в requirements, но не используется
   - Статус: Сканы без OCR не индексируются в ChromaDB
   - Решение: Добавить OCR в `normbase/` пайплайн
   - Время: ~1-2 дня

### 🟡 Medium Priority Issues

4. **Тестовое покрытие ~40%**
   - Проблема: 7 тестов, но много критических компонентов не покрыты
   - Статус: нет тестов для router, config, document_generator
   - Решение: Добавить unit и интеграционные тесты
   - Время: ~2 дня

5. **Обновление расценок не автоматизировано**
   - Проблема: pricing_db.py работает, но нет скрипта загрузки актуальных цен
   - Статус: Manual update требуется
   - Решение: Добавить `scripts/update_pricing.py` с источниками данных
   - Время: ~1 день

6. **Документация API минимальна**
   - Проблема: Swagger генерируется, но примеры запросов в `/docs` скудны
   - Статус: Сложно новичку начать
   - Решение: Добавить примеры в docstrings, расширить README
   - Время: ~1 день

7. **Error handling в некоторых компонентах слабый**
   - Проблема: Нет graceful fallbacks при недоступности LM Studio
   - Статус: Крах вместо информативной ошибки
   - Решение: Добавить try-except с логированием ошибок
   - Время: ~1 день

### 🟢 Low Priority Issues

8. **GSPLAT pipeline не интегрирован**
   - Проблема: `gsplat_pipeline.py` существует, но не используется
   - Статус: Экспериментальный компонент
   - Решение: Либо завершить, либо удалить
   - Время: ~3-4 дня (если завершать)

9. **Versioning моделей в ChromaDB**
   - Проблема: Нет отслеживания версий embedding-модели
   - Статус: Переиндексация при обновлении модели может быть трудной
   - Решение: Добавить metadata с версией
   - Время: ~0.5 дня

10. **Performance metrics отсутствуют**
    - Проблема: Нет сбора метрик времени ответа, качества RAG
    - Статус: Сложно оптимизировать
    - Решение: Добавить prometheus метрики
    - Время: ~1 день
