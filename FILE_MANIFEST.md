### ✅ 2. Интеграция Kagglehub

**5 новых компонентов:**

#### 📜 `scripts/download_kaggle_dataset.py` (259 строк)

Основной скрипт для загрузки и интеграции датасетов с Kaggle в RAG систему.

**Функциональность:**
- `download_kaggle_dataset()` — скачивание датасетов через kagglehub
- `integrate_dataset_into_rag()` — парсинг и индексация файлов
- `normalize_dataset_text()` — нормализация текста для RAG
- `list_available_datasets()` — вывод популярных датасетов

**Поддерживаемые форматы:**
- PDF (через pdfplumber)
- TXT (plain text)
- MD (markdown)

**Использование:**
```bash
python scripts/download_kaggle_dataset.py \
  --dataset "lkerkarabulut/rplan-dataset2025" \
  --output data/datasets \
  --integrate-rag
```

## 🚀 Быстрый старт

### Этап 1: Подготовка

```bash
cd ~/botarbitraj
pip install -r requirements.txt
```

### Этап 2: Аутентификация

```bash
# Установить Kaggle API ключ
kagglehub auth login

# Введите:
# - Username: ваше имя на Kaggle
# - API Key: из настроек аккаунта
```

### Этап 3: Загрузить датасет

```bash
# Вариант 1: Основной датасет (рекомендуется)
python scripts/download_kaggle_dataset.py \
  --dataset "lkerkarabulut/rplan-dataset2025" \
  --integrate-rag

# Вариант 2: Быстрый пример
python examples/quick_kaggle_load.py

# Вариант 3: Просмотр доступных датасетов
python scripts/download_kaggle_dataset.py --list
```

### Этап 4: Запустить веб-приложение

```bash
./start_webapp.sh
# Backend: http://localhost:8765
# Frontend: http://localhost:5173
```

### Этап 5: Использовать в чате

1. Откройте http://localhost:5173
2. Перейдите на вкладку **"Чат с ботом"**
3. Включите **"RAG"** (переключатель)
4. Вводите запросы:
   - "Какие стандартные размеры комнат?"
   - "Покажи примеры планов квартир"
   - "Какие нормы для лестниц?"
